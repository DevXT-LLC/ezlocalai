# Native worker on llama.cpp v0.7.0, RTX 3090 Ti, 2026-10-20

This repeats the
[native vs Python benchmark](cpp-vs-python-3090ti-20261019.md) after moving the
native engine from llama.cpp b11549 (`aa94f20`, the Python reference's pin) to
release v0.7.0 (`620d222`). The host, `.env`, model files, unregistered-worker
setup, prompt prefix and [`bench_api.py`](bench_api.py) are all unchanged. Raw
timings are in
[native-llama-v070-3090ti-20261020.json](native-llama-v070-3090ti-20261020.json).

There are two v0.7.0 builds:

- **Portable** (image `529dd8fb7c73`, deployed). llama.cpp,
  stable-diffusion.cpp and ACE-Step are built with `GGML_NATIVE=OFF`, so
  the image runs on every fleet CPU.
- **`-march=native`** (image `2a53e9da4fd1`). This was the previous build
  default, tuned for the Alder Lake build host. It may not start on Haswell or
  Zen hosts.

## Findings

- **Prompt-cache reuse is about 30% faster on v0.7.0.** A repeated 29.7k-token
  prompt returns its first token in 0.19 s instead of 0.27 s. A follow-up turn
  takes 0.42 s instead of 0.59 s. This matches the release's improved slot and
  prompt-cache restore, and is the largest gain for agent and chat workloads
  that resend long histories.
- **Cold prefill is 2–4% faster** in the portable build than on b11549 (1524
  vs 1463 tok/s at 7.6k tokens, and 1043 vs 1020 at 89.4k). It is also slightly
  ahead of the `-march=native` build, so dropping host-CPU tuning costs nothing
  measurable with full GPU offload.
- **Decode speed is unchanged within noise.** Per-request decode tracks how
  many speculative MTP draft tokens are accepted, and that varies with each
  run's prompt. Examples:
  - 161 of 280 drafts accepted gave 84.0 tok/s; 118 of 407 gave 58.4 tok/s.
  - Individual runs: portable 58.4–71.3, `-march=native` 64.9–69.5,
    b11549 61.6–84.0, Python 63.7–76.6.

  Three samples per build cannot separate these.
- **Warm restart to first chat is unchanged** at 6.2 s once model files are in
  the page cache. The first start after an image change takes about 12 s.
- **Media outputs** were rechecked on v0.7.0: embeddings (cosine 0.9994–0.9998
  to Python), byte-identical STT, and TTS, image and music returned through the
  same API. Production registration, routed chat and streaming pass.
  llama-server reports `b11669-620d2225c`.
