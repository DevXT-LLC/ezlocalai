## Technical Format

- **Container**: WAV (PCM)
- **Sample rate**: 24000 Hz
- **Channels**: 1 (mono)
- **Bit depth**: 16-bit signed integer
- **Duration range**: ~5-15 seconds per clip

## Notes

- These are reference clips for zero-shot TTS voice cloning, not full recordings.
- Each clip captures a unique vocal timbre, accent, and speaking style.
- The voices-emotion/ directory in the source repo contains per-emotion variants (anger, calm, excited, etc.) which are NOT included here — only the base neutral clips from voices/.
- Star Trek TNG Computer: No CC0 source exists (Paramount copyright). Only the pre-existing TOS-era StarTrekComputer1.wav is available.
